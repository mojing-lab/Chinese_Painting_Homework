# 第1周：PyTorch与卷积基础（5天）

| 天数   | 内容                                                          | 目标                                                    |
|--------|---------------------------------------------------------------|---------------------------------------------------------|
| 第1天  | 安装PyTorch；加载MNIST；张量操作；.backward()                  | 熟悉张量与自动求导流程                                   |
| 第2天  | 线性回归与Softmax多分类                                       | 理解训练循环与损失优化                                   |
| 第3天  | LeNet-5实现；引入Dropout、BatchNorm                           | 掌握基础CNN结构与正则化技术                             |
| 第4天  | CIFAR-10数据增强；训练简易CNN                                | 熟悉torchvision.transforms与模型搭建                   |
| 第5天  | 特征图可视化（Matplotlib + hooks）                            | 理解卷积层中间表示，能提取并解读特征                    |

# 第4周：风格迁移与条件GAN（7天）

| 天数   | 内容                                                          | 目标                                                    |
|--------|---------------------------------------------------------------|---------------------------------------------------------|
| 第16天 | Gatys优化法风格迁移：VGG19内容/风格特征提取；优化输入图像   | 实现高质量单张图像风格迁移                              |
| 第17天 | 调整Gram损失权重；多种画风实验（国画、素描、油画）           | 比较不同风格迁移效果                                    |
| 第18天 | 快速风格迁移（fast_neural_style）；实时转换                   | 掌握网络化风格迁移方法                                  |
